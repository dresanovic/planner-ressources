# I-012 — Standard Optimized

Add the operator-selected `standard_optimized` strategy without changing Standard's search implementation or its recorded deterministic behavior. Reuse Standard's detached inputs, candidate generation, hard-constraint/resource helpers, result types, worker, independent validation, and atomic review/save workflow. Copy only its search/model orchestration into the extension module.

## Acceptance criteria

1. Selecting `standard_optimized` in installation policy dispatches a separate implementation and displays “Standard optimiert” throughout preparation, progress, review and saved results. Omitted selection still means Standard. The live policy is not switched automatically.
2. Given full demand that fits early but also has later feasible weeks, the new strategy spreads each course's teaching across its effective planning period. Minimize cumulative weekly-unit deviation from a uniform distribution over feasible weeks, after coverage, intensive use, daily variety and conflicts, before Standard's lower arrangement preferences. This is a soft preference; holidays, protected occupancy, course limits and resource availability remain hard.
3. Reserve stage budgets using weights 35/5/5/0/40/5/2/2/2/2/2 for coverage, intensive use, variety, conflicts, weekly spread, shape, lecturer changes, room changes, retained drafts, temporal ordering and resource ordering. Each stage gets its proportional share of the remaining allowance, so unused time rolls forward. When no usable initial candidate exists, coverage may use the whole remaining allowance. Stop coverage proof search when every course's required units are scheduled, including when a validated constructive candidate already attains that mathematical upper bound. Once a stage ends, freeze its best feasible value before lower priorities; never trade it away. A bounded stage can leave an earlier optimum unproven.
4. Proof evidence uses a distinct `standard-optimized-v1` profile and ordered `weekly_spread` objective. Later optimum proofs under an unproven fixed earlier value are conditional, never globally proven. Report bounds only for coverage and require explicit whole-selection acceptance for this new algorithm, including complete candidates. Unknown/time-limited stages do not invent infeasibility or preference proof.
5. Preserve cancellation/deadline/checkpoint handling, relevant-input freshness checks, protected data and exactly-once atomic saving. Policy changes do not retarget an already-started run. A database upgrade expands allowed identifiers/profiles while preserving existing receipts and saved JSON.
6. Existing Standard search behavior and baseline outputs remain unchanged. The shared completion-hint helper may be factored to expose its existing deterministic construction without changing Standard's decisions. Existing Cohort, Lecturer, exam and navigation behavior remain supported.
7. For generated-only first runs, construct a starting candidate from legal candidates before building the expensive solver model. Independently validate any nonempty candidate, evaluate all eleven objective values using the same definitions as the exact model, and publish it through the existing checkpoint mechanism. Keep it as an incumbent throughout model construction and optimization; preserve ordered quality and disclose unproved preferences. Deadline expiry during model construction or solver preprocessing returns the best available candidate for explicit whole-selection review. Cancellation still discards the run. No schedules are written before acceptance.
8. A bounded no-candidate exit for `standard_optimized` must use its own completion label, never the heuristic label. A global deadline is reported as a deadline. No-candidate wording and proof evidence must not claim infeasibility.
9. Generated-only starts compare an independently validated saved arrangement with chronological and semester-spread constructions using the same ordered objective values. Recompute evidence under current inputs; stale or invalid saved sessions are not used. Preserve the best valid arrangement and continuation incumbents. The spread construction visits intensive opportunities first and distributes ordinary dates over feasible weeks. A bounded constructive pass may relocate ordinary sessions to improve weekly spread while preserving their units and intensive presence; no higher priority is traded away.
10. The generated-only exact model shares time and resource decisions per course/date: at most one session per course/day permits one variable interval per day and resource. Preserve every original temporal candidate, its exact eligible resources and candidate-specific resource rank. Do not reduce the date grid or drop alternatives. Retained-plan direct callers and original Standard behavior remain supported. Compact and original formulations must produce the same objective values and legality on small exact oracle cases.

## Non-goals

No new algorithm picker, per-course cadence UI, mandatory full-semester attendance, dynamic plugin loader, activation of the new policy, or changes to current saved plans. Existing course planning periods determine the teaching interval.

## Starting-plan regression scenarios

- Given a nonempty independently validated construction, when model building or solver preprocessing exhausts the allowance, then the proposal remains reviewable with accurate coverage and unproved preference evidence; no schedule is saved automatically.
- Given a construction covering every requested unit, when exact optimization begins, then coverage is fixed at its mathematical upper bound and the coverage solve is skipped.
- Given no usable construction, when coverage optimization begins, then it can use the whole remaining allowance and does not terminate solely because the normal 35% share elapsed.
- Given a candidate checkpoint, when the user cancels, then the run is cancelled and the candidate cannot be accepted.
- Given a valid saved arrangement better than a fresh construction, when a new run starts, then the saved arrangement is evaluated under current constraints and kept until a lexicographically better valid proposal exists.
- Given legal later weeks and an exact-solver timeout, when a spread construction preserves higher priorities, then the returned proposal already extends teaching over the effective period.
- Given candidate-specific resource availability, when the compact model chooses a session, then its resource identities and rank costs match the original candidate model exactly.
